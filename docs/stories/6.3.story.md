# Story 6.3: Header & Footer Re-skin

## Status

review

## Story

**As a** developer re-skinning the site to the Atlas design system,
**I want** the site header (sticky nav, emerald underline links, `.lang` globe pill, "Book a Call" CTA, mobile drawer) and footer (ink background, 4-column grid) rebuilt to match the Atlas reference, with the scroll-progress bar wired and Atlas logo marks integrated,
**so that** the global chrome — the first and last thing on every page — visually matches Atlas while preserving i18n, routing, and accessibility.

## Acceptance Criteria

1. **Header shell** — `header.tsx` renders the Atlas sticky nav: warm-paper translucent background with backdrop blur (`header.nav` style), `78px` height, a `scrolled` state that adds the `--line` border + soft shadow once the page scrolls past `8px`.
2. **Logo mark** — the Atlas "arrow + S" logo SVG (`logo-mark.svg`, emerald arrow `#0E8C5A` on ink `#15201B`) renders at ~24px height beside the "Scalenty" wordmark (Space Grotesk / `font-disp`, `33px`, `-0.025em` tracking) in the header, linked to `/`.
3. **Desktop nav links** — nav items render as Atlas underline links: `--ink-2` color, emerald (`--green`) 2px underline that animates from 0→100% width on hover and is full-width + `--ink` colored when `active`. Active state is driven by `usePathname()` (preserve existing `isActive` logic). The shadcn `NavigationMenu` dropdown is replaced by the flat Atlas link row.
4. **Nav order & items** — the desktop link row matches Atlas: Home, Amazon, Etsy, Pricing, About, FAQ (note Atlas exposes Amazon/Etsy as **top-level** links and adds **Home** + **FAQ**, unlike the current Services-dropdown structure). All labels route through `useLanguage()` / `getTranslations()`; no hardcoded strings.
5. **Language pill** — the `LanguageToggle` is restyled to the Atlas `.lang` globe pill: bordered (`--line`) rounded pill, `font-disp`, with a globe glyph and `EN / TR` style indicator where the active locale is bold (`--ink`) and the inactive is muted (`--soft-2`). Clicking still toggles locale via the existing `useLanguage().setLocale`. Hover sets border to `--ink`.
6. **Header CTA** — a "Book a Call" button (`btn-green` Atlas style) appears in the desktop nav-right cluster, linking to `/contact`. Label is i18n-driven (new `nav.bookCall` key in EN/TR).
7. **Mobile nav** — the hamburger toggle shows below the Atlas `860px` breakpoint; the mobile drawer lists all nav links + a "Book a Call" link in Atlas mobile styling. i18n preserved; drawer closes on route change.
8. **Footer** — `footer.tsx` rebuilt to Atlas: ink (`--ink` `#15201B`) background, white text, `80px 0 40px` padding, 4-column grid (`1.7fr 1fr 1fr 1fr`) collapsing to 2 columns below `760px`. Columns: brand+tagline, Quick Links, Services, Contact (with Privacy/Terms). Section headings (`h5`) use mint `#6FD3A4`, uppercase, `0.1em` tracking, Space Grotesk.
9. **Footer logo** — the on-dark logo mark (`logo-mark-on-dark.svg`, mint arrow `#6FD3A4` on off-white `#FAF9F5`) renders beside the "Scalenty" wordmark (white) in the footer brand column.
10. **Footer bottom bar** — a `foot-bot` row with `© {year} Scalenty. All rights reserved.` (i18n) and a secondary tagline, separated by a `rgba(255,255,255,.13)` top border. Links route through i18n.
11. **Scroll-progress bar** — a fixed `3px` top progress bar (green→clay gradient) reflects scroll position, implemented as a React component/hook using scroll listener or `requestAnimationFrame`, mounted globally (in `app/layout.tsx` or via the header). Honors `prefers-reduced-motion` only insofar as it has no entrance animation (the bar itself is a functional indicator).
12. **i18n intact** — every label/heading in header, footer, mobile nav, and language pill reads from `getTranslations(locale)`; switching EN↔TR updates all chrome text. New keys (`nav.bookCall`, any new footer keys) added to both `en` and `tr` blocks of `lib/translations.ts`.
13. **Tests** — `tests/components/layout/header.test.tsx`, `footer.test.tsx`, and `mobile-nav.test.tsx` are updated to match the new markup/classes (the footer test's `bg-muted` and `md:grid-cols-2`/`lg:grid-cols-4` assertions, and any header NavigationMenu assertions, will need updating). A scroll-progress test is added if a testable component is introduced.
14. **Build & a11y** — `npm run build` succeeds; header is a `<header>` landmark, footer is `<footer>`/`contentinfo`, nav has an accessible name, the language pill and hamburger have `aria-label`s, and the logo link has an accessible name ("Scalenty").

## Dev Notes

### Why
The header and footer are shared chrome that appears on every one of the site's 16 routes. Re-skinning them is the highest-leverage single step in the Atlas migration: it changes the immediate visual impression site-wide and unblocks the per-page stories (6.5–6.11), which all sit between this chrome. Story 6.1 already landed the tokens (`--green`, `--ink`, `--line`, `--font-disp`, `--maxw`, `.wrap`, shadows) and Story 6.2 removed dark mode and the `<ThemeToggle />` from both `header.tsx` and `mobile-nav.tsx`. This story consumes those tokens.
