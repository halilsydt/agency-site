# Story 6.4: Buttons & UI Primitives Re-skin

## Status

review

## Story

**As a** developer re-skinning the site to the Atlas design system,
**I want** the shared UI primitives — `Button`, form fields (`Input` / `Textarea` / `Select`), badges & pills (`Badge`, `PlatformBadge`, `PillToggle`), `Card`, and the FAQ `Accordion` — re-skinned to Atlas tokens and component styling,
**so that** every page that composes these primitives (homepage, services, pricing, about, contact, FAQ) inherits the correct Atlas look automatically before the per-page stories (6.5–6.11) run, with i18n, accessibility, and behavior fully preserved.

## Acceptance Criteria

1. **Button variants → Atlas** — `components/ui/button.tsx` is re-skinned so its variants map to the Atlas button styles (`atlas.css:35–43`):
   - `default` → `.btn-green`: `bg-green text-white`, soft emerald glow shadow (`0 10px 24px -10px rgba(14,140,90,.6)`), hover `bg-green-d` + `-translate-y-0.5` + stronger glow.
   - `secondary` → `.btn-ink`: `bg-ink text-white`, hover `bg-ink-2` + `-translate-y-0.5`.
   - `outline`/`ghost` → `.btn-ghost`: `bg-transparent text-ink border-line` (1.5px), hover `border-ink` + `bg-surface`.
   - `link` → unstyled-ish text link in `text-green` with underline-on-hover (keep close to current behavior).
   - Base button adopts Atlas geometry: `font-disp font-semibold`, `gap-[9px]`, `rounded-xl` (12px), Atlas easing `ease-[cubic-bezier(.2,.7,.3,1)]`, `border-[1.5px] border-transparent`, and the icon nudge (`[&_svg]:size-[17px]`, hover `[&_svg]:translate-x-[3px]` on green). Padding matches Atlas `14px 24px` (default size).
   - The `accent` and `destructive` variants are retained (CTAs use `accent` on `bundle-highlight.tsx`); re-skin `accent` to a clay treatment (`bg-clay text-white`, hover darker) and keep `destructive` functional. **No variant is removed** (consumers and the style guide reference all of them).
2. **Button sizes preserved** — `sm` / `default` / `lg` / `icon` size keys remain (consumers pass `size="lg"`, `size="sm"`, `size="icon"`). Heights stay distinguishable (`sm` ≈ h-8/9, `default` ≈ h-10/11, `lg` ≈ h-12) so existing size tests can assert a stable height class. The `asChild` (Radix `Slot`) path and `buttonVariants` export are unchanged in signature.
3. **Form fields → Atlas `.field`** — `Input`, `Textarea`, and `SelectTrigger` adopt the Atlas field styling (`atlas.css:324–326`): `font-sans`, `text-[15px]`, `text-ink`, `bg-bg` (warm paper) or transparent, `border border-line`, `rounded-xl` (12px), `~13px 15px` padding; focus → `border-green` + `bg-surface` + `ring`-equivalent `0 0 0 4px rgba(14,140,90,.1)` glow (no default browser outline). `Textarea` keeps `min-h-[120px]` and `resize-vertical`. Disabled/placeholder states preserved.
4. **Field labels** — the form `Label` / `FormLabel` reads as Atlas: `font-disp font-semibold text-[13.5px]` (`atlas.css:323`). Error state keeps the existing `text-destructive` treatment (re-skin not required to break validation styling).
5. **`Badge` → Atlas pill** — `components/ui/badge.tsx` variants are re-skinned to Atlas tokens (rounded pill, `font-disp font-semibold`, emerald/ink/clay treatments rather than the old `bg-primary`/`bg-secondary`). The "Most Popular" badge on `pricing-card.tsx` (`variant="default"`) renders as an Atlas emerald pill. All four variants (`default`, `secondary`, `destructive`, `outline`) remain defined.
6. **`PlatformBadge` → Atlas** — `components/ui/platform-badge.tsx` renders the Atlas platform tag treatment: Amazon = ink/green family, Etsy = clay (`bg-clay-soft text-clay`), `font-disp`, rounded-full pill (mirror `atlas.css:163–165` `.panel .tag`). Keep the `platform`/`size` variant API and the `capitalize` label behavior. (It may keep using the `badge-amazon-*` / `badge-etsy-*` semantic tokens **if** those already resolve to Atlas values — verify in `globals.css`; otherwise switch to named Atlas tokens `clay`/`clay-soft`/`green`/`ink`.)
7. **`PillToggle` → Atlas `.seg`** — `components/ui/pill-toggle.tsx` is re-skinned from the shadcn `bg-muted` look to the Atlas segmented control (`atlas.css:260–263`): outer `inline-flex bg-surface border border-line rounded-[14px] p-[5px] gap-1 shadow-sh-sm`; option buttons `font-disp font-semibold text-[15px]`, `rounded-[10px]`, inactive `text-soft`, **active `bg-ink text-white`**. The existing sliding-indicator approach may be kept (animate the `bg-ink` indicator) **or** simplified to per-button active background — either is acceptable as long as the active option reads ink-on-white per Atlas and the toggle still calls `onChange`. Keep the `options`/`value`/`onChange` API.
8. **`Card` → Atlas surface** — `components/ui/card.tsx` base `Card` adopts the Atlas card surface: `bg-surface border border-line rounded-3xl` (~22–24px), Atlas shadow on hover where appropriate. **Do not bake in hover-lift/transform on the base `Card`** — per-page stories (6.5+) apply context-specific hover (`.panel`/`.tier`/`.member`) on their own card wrappers; the base primitive should be a calm Atlas surface (border + radius + subtle/no shadow) so it doesn't double-up. Sub-parts (`CardHeader`/`CardContent`/`CardTitle`/`CardDescription`/`CardFooter`) keep their layout roles; `CardTitle` uses `font-disp`. Padding/spacing may stay as-is or align to Atlas; the key change is bg/border/radius/token usage (drop `bg-card`/`text-card-foreground` reliance only if it doesn't already resolve to Atlas — verify).

If keeping the chevron, place it in an Atlas emerald-soft circular affordance for visual parity; the rotate-on-open behavior is preserved either way.

10. **i18n & behavior preserved** — none of these primitives hardcode copy; all labels continue to come from consumers via `getTranslations()`. Form validation (react-hook-form + zod in `contact-form.tsx`), the platform `Select` values (`amazon`/`etsy`/`both`), the pricing `PillToggle` switching, and the FAQ accordion expand/collapse all behave exactly as before.
