# Story 6.1: Atlas Design Tokens & Typography Foundation

## Status

Review

## Story

**As a** developer re-skinning the site to the Atlas design system,
**I want** Atlas's color tokens, typography, shadows, and radii wired into the Tailwind config and global stylesheet, with the Atlas fonts loaded,
**so that** every component can be restyled against a single, correct source of design tokens in subsequent stories.

## Acceptance Criteria

1. Space Grotesk (display) and Hanken Grotesk (text) are loaded via `next/font/google` and exposed as CSS variables (`--font-display`, `--font-sans` or equivalent), replacing Nunito.
2. `tailwind.config.ts` `fontFamily` exposes `disp` (Space Grotesk) and `sans` (Hanken Grotesk) families matching Atlas usage.
3. The Atlas color tokens from `atlas.css` `:root` are available as Tailwind colors and/or CSS variables: `bg`/`bg-2`, `surface`, `ink`/`ink-2`, `soft`/`soft-2`, `line`, `green`/`green-d`/`green-soft`, `clay`/`clay-soft`.
4. Atlas shadow tokens (`--sh-sm`, `--sh-md`, `--sh-lg`) and the `--maxw: 1180px` container width are available (Tailwind `boxShadow` + a `.wrap` utility or `max-w` token).
5. `body` background is warm paper (`#F7F6F1`), default text is ink (`#15201B`), and base font is Hanken Grotesk — visible on any existing page.
6. Headings (`h1`–`h6`) default to the display font (Space Grotesk) with Atlas tracking, matching `atlas.css`.
7. A `.wrap` container utility (`max-width: 1180px; margin: 0 auto; padding: 0 36px`) exists and matches Atlas.
8. `npm run build` succeeds and `npm test` passes (token-only test updates allowed; no component restyle in this story).

### Architectural guidance

Document the mapping in the file.
- The `.dark` block is removed in Story 6.2 — leave it for now (or remove here if trivial; coordinate so 6.2 isn't left empty).
- Do not change the theme-detection `<script>` in layout yet (that's 6.2). Only swap the font here.
- Preserve `--font-nunito` references only if something still needs them; otherwise rename cleanly to `--font-display` / `--font-sans`.
